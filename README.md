# Ola Bike Ride Demand Forecasting Using Machine Learning

## Project Overview

This project predicts Ola bike ride demand using Machine Learning techniques. The model analyzes weather, seasonal, and user-related features to forecast ride demand patterns.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

---

## Machine Learning Model

- Random Forest Regressor

---

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Feature Engineering
4. Exploratory Data Analysis (EDA)
5. Model Training
6. Prediction
7. Model Evaluation
8. Feature Importance Analysis

---

## Model Performance

- MAE: 25.63
- RMSE: 32.09
- R² Score: 0.82

---

## Key Insights

- Registered users contribute most to ride demand.
- Weather and temperature affect booking patterns.
- Random Forest performed well for forecasting.
